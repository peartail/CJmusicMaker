# MusicBitMaker 단축키 설정 기능 기획서

작성일: 2026-10-17 · 갱신일: 2026-10-24 · 상태: v0.1036 재생 단축키 확장 구현 · 대상: Windows x64 네이티브 앱

## 1. 목적과 범위

사용자가 화면 건반과 드럼 패드를 보면서 연주·재생 단축키를 확인하고 바꿀 수 있게 한다. 설정 진입점은 **`Edit > Shortcuts...`** 이다. 창에는 3옥타브 피아노, 네 가지 드럼 패드, 음역 이동, Play/Stop, Loop 동작을 그림으로 표시한다. 그림의 각 대상에는 현재 지정된 단일 키를 직접 적는다.

현재 범위는 피아노 연주, 드럼 연주, 건반 표시 음역 이동, Play/Stop과 Loop다. 피아노의 36개 음은 각각 별도의 단일 키를 지정하거나 비워 둘 수 있다. Alt/Shift를 누른 상태로 다른 옥타브를 연주하는 기능은 포함하지 않는다. 프로젝트 저장·편집과 Record 같은 일반 명령은 아직 재지정하지 않는다. 마우스 연주와 기존 MIDI 노트 데이터는 단축키 변경의 영향을 받지 않는다.

## 2. v0.1021 구현 결과

- 메뉴는 `File`, `Edit`, `View`이며 `Edit > Shortcuts...`에서 설정 창을 연다.
- 공통 `ShortcutMap`이 메인 창, 별도 건반 창, 설정 창의 키 해석과 표시를 담당한다.
- 피아노 36음, 드럼 네 개, Kick 보조 키, 음역 내림/올림을 지정하거나 해제할 수 있다.
- `ApplicationProperties`에 스키마 버전과 키 코드를 저장하며, 값이 없거나 손상됐으면 기본값으로 복구한다.
- 설정 창 열기·적용, 음역·포커스·트랙 변경 시 기존 음을 먼저 종료한다. 드럼 키 반복 입력은 한 번 누를 때 한 번만 타격한다.

관련 구현 위치: `src/Main.cpp`의 `MainComponent` 메뉴·키 입력, `KeyboardPadComponent` 입력·그리기, `triggerDrum`, `updateCombinedLiveNote`, `releaseAllLiveNotes`.

### v0.1024 확장

- 설정 창의 Root와 Scale 선택기로 C~B × Major/Natural Minor의 24개 피아노 단축키 프로필을 편집한다.
- 건반 창의 Root/Scale을 바꾸면 대응하는 피아노 프로필이 즉시 활성화된다.
- 드럼과 옥타브 이동은 음악의 음계와 무관하므로 모든 프로필이 같은 공통 키를 사용한다.
- 기존 스키마 1의 단일 맵은 24개 프로필 모두의 시작값으로 가져와 사용자 설정을 잃지 않는다.

### v0.1036 확장

- Kick 보조키를 제거하고 기본 Space를 Play/Stop 토글에 배정한다.
- Play/Stop과 Loop를 음계와 무관한 공통 단축키로 추가한다. Loop 기본값은 미지정이다.
- PLAY와 STOP을 한 버튼으로 합치고, 상단의 네 드럼 버튼은 제거한다. 드럼 키 Z/X/C/V는 유지한다.
- 기존 스키마 1·2 설정은 피아노·드럼·옥타브 배치를 보존하면서 스키마 3으로 변환한다.

## 3. 확정된 기본 배치

가운데 옥타브의 흰 건반은 요청대로 `A S D F G H J`다. 검은 건반은 기존의 `W E T Y U`를 사용한다. 왼쪽·오른쪽 옥타브는 처음에는 **미지정**이며, 설정 창에서 각 음에 원하는 단일 키를 직접 배정한다. `N`은 화면 음역을 한 옥타브 내리고 `M`은 올린다. `K`는 기본 연주 배치에서 제외한다.

| 음 | C | C♯ | D | D♯ | E | F | F♯ | G | G♯ | A | A♯ | B |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 가운데 | A | W | S | E | D | F | T | G | Y | H | U | J |
| 왼쪽 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 |
| 오른쪽 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 | 미지정 |

| 동작 | 제안 기본값 | 현재 동작과의 관계 |
| --- | --- | --- |
| 화면 음역 내림 / 올림 | N / M | 건반 창의 Z/X를 대체 |
| Kick | Z | 단일 드럼 키 유지 |
| Snare | X | 현재 메인 창 입력 유지 |
| Closed Hat / Open Hat | C / V | 현재 메인 창 입력 유지 |
| Play / Stop | Space | 한 버튼과 같은 토글 동작 |
| Loop | 미지정 | 설정 창에서 원하는 키 지정 |

**기본 음높이:** 새 프로젝트는 C3~B5로 시작해 가운데 옥타브가 C4~B4가 된다. 기존 프로젝트는 저장된 시작 옥타브를 유지하고, 옥타브 값이 없는 옛 프로젝트는 이전 기본값 C4 시작을 유지한다.

## 4. 설정 화면

메뉴에서 `Shortcuts...`를 열면 별도 설정 창이 뜬다. 창은 다른 연주 입력을 가로채지 않도록 **설정 모드**가 된다. 설정 창이 활성화된 동안 누른 키는 소리를 내지 않고 새 바인딩 후보로만 처리한다.

현재 건반 창은 항상 위에 표시되므로 설정 창을 열 때 누른 음을 종료하고 설정 창을 그보다 앞에 놓는다. 설정 창을 닫으면 기존 건반 창의 표시와 포커스를 복구한다.

```text
Edit > Shortcuts...
┌─────────────────────────────────────────────────────────────┐
│  왼쪽 음역        가운데 음역          오른쪽 음역           │
│  ┌────────── 3옥타브 피아노 그림 · 각 음에 키 표시 ──────┐ │
│  │ C3 ... B3  │  C4 ... B4  │  C5 ... B5              │ │
│  └───────────────────────────────────────────────────────┘ │
│  선택: 가운데 C4   현재: A                                  │
│  [새 키 입력]  [해제]  [기본값 복원]                          │
│  충돌 또는 예약 키 안내                                     │
│                                          [취소] [적용]       │
└─────────────────────────────────────────────────────────────┘
```

- **Piano:** 한 화면의 피아노 그림에서 36개 음 중 하나를 클릭하면 음 이름과 현재 단축키를 보여 준다. 각 음의 키를 독립적으로 지정하거나 해제한다. 미지정 건반에는 `-`를 표시하며 마우스로는 계속 연주할 수 있다.
- **Drums:** 같은 화면 아래쪽에 Kick, Snare, Closed Hat, Open Hat을 표시한다. 각 패드에 현재 키를 표시한다.
- **Controls:** 같은 화면에서 음역 내림/올림, Play/Stop, Loop의 현재 키를 표시하고 다른 단일 키로 지정할 수 있다.
- 외부 이미지 파일 대신 JUCE로 건반과 패드를 직접 그려 Windows DPI 배율에서도 선명하게 표시한다. 선택된 음과 설정 중인 대상은 별도 테두리로 구분한다.
- 키 할당은 그림의 대상을 선택 → `새 키 입력` → 단일 키 누르기 → 충돌 확인 → `적용` 순서다. `Esc`는 입력 대기만 취소한다. `취소`는 창에서 바꾼 전체 내용을 버리고, `기본값 복원`은 적용 전 미리보기만 바꾼다.

## 5. 입력 및 충돌 규칙

1. 피아노 키는 **건반 창에 포커스가 있을 때** 우선 연주한다. 메인 창에서도 같은 배치를 사용할 수 있게 연결하되, 메뉴·대화상자·텍스트 편집·단축키 설정 창에 포커스가 있을 때는 연주하지 않는다. 드럼은 메인 창에서 기존처럼 연주한다.
2. 한 단일 키가 피아노 음, 드럼 타격, 음역 이동 중 둘 이상에 배정되면 충돌을 표시하고 `기존 할당 대체` 또는 `취소`를 선택하게 한다. 피아노와 드럼이 서로 다른 창에 있어도 동일 키 중복은 허용하지 않아 창을 바꿔도 의미가 분명하다.
3. 연주 단축키에는 보조키 조합을 사용하지 않는다. Ctrl/Alt/Shift, Windows 키, Escape, Delete/Backspace 같은 시스템·편집 키는 단일 연주 키로 지정할 수 없다. 기존 `Ctrl+N/O/S`, `Ctrl+Shift+S` 등 앱 명령은 그대로 동작한다.
4. Windows 한글/영문 입력 상태와 키보드 반복 입력에서 같은 물리 키가 같은 음을 가리키는지 확인한다. 키보드 배열에 따라 사용할 수 없는 키는 설정 창에서 명확히 안내한다.
5. 누른 키가 가리킨 **실제 MIDI 음높이와 입력 출처**를 키 해제 때까지 기억한다. 화면 음역 변경, 설정 적용, 포커스 이탈, 창 닫기, 트랙·악기 변경 시 기존 음을 먼저 종료한다. 이미 녹음된 MIDI 노트의 음높이는 바꾸지 않는다.
6. 드럼 키를 길게 누르거나 OS 반복 이벤트가 와도 의도하지 않은 연속 트리거가 일어나지 않도록 한 번의 키 누름을 한 번의 타격으로 취급한다.

## 6. 설정 데이터와 코드 구조

- 단축키는 프로젝트의 음악 데이터가 아니라 **사용자 앱 설정**으로 저장한다. 모든 프로젝트에 같은 24개 음계 프로필이 적용되며, `.tracktionedit` 파일에는 기록하지 않는다. 기존 `juce::ApplicationProperties`를 사용한다.
- 설정에는 `schemaVersion`, Root/Scale별 피아노 36개 음의 키 또는 미지정 상태, 공통 드럼·음역 이동·Play/Stop·Loop 키를 둔다. 값이 없거나 손상됐으면 기본 배치를 적용한다. `적용` 시 검증과 저장을 마친 뒤 두 입력 창과 표시 라벨을 동시에 갱신한다.
- 단일 키 해석을 한 곳의 `ShortcutMap`/입력 디스패처로 모으고 `MainComponent`, `KeyboardPadComponent`, 설정 창은 이를 사용한다. 건반·드럼 음원 및 녹음 상태는 계속 Tracktion Edit가 담당한다.
- 저장 형식은 표시 문자보다 키 코드를 기준으로 한다. JUCE 입력이 한글 IME 상태에서 다른 코드로 들어오는 경우 Windows 키 식별 방식을 별도로 확인한다.
- 파일 저장, 설정 UI, 로그 작성은 JUCE 메시지 스레드에서만 한다. 실시간 오디오 콜백에는 단축키 처리나 파일 입출력을 넣지 않는다.
- 사용자 설정 형식에는 버전을 두어 이후 키 재지정 범위가 늘어도 옛 설정을 읽을 수 있게 한다. 설정 창의 단축키 표시는 실제 디스패처와 같은 데이터를 사용한다.

자동 검사는 36음 매핑/충돌/설정 왕복과 Note On/Off 전환에 집중한다. 실제 Windows 앱에서는 세 옥타브에 지정한 키를 직접 연주하고 드럼 및 녹음 결과를 확인한다. 표준 빌드와 `--self-test-keyboard-octave`, 전체 `--self-test`도 다시 실행한다.

## 9. 확정된 결정

1. **새 프로젝트 기본 음역:** C3 시작으로 확정했다. 기존 프로젝트의 값은 유지한다.
2. **메인 창의 연주 범위:** 건반 창과 같은 36음 매핑을 사용한다.
3. **왼쪽·오른쪽 기본값:** 미지정으로 시작한다.
4. **일반 명령 확장:** Play/Stop과 Loop까지 편집하며 Record와 파일 명령 재지정은 후속 범위다.
5. **설정 적용 범위:** 모든 프로젝트에 공통인 사용자 설정으로 저장한다.

v0.1036에서 재생 단축키와 기존 설정 마이그레이션까지 코드와 문서에 반영했다. SC-08의 실제 Windows 한글/영문 입력 및 키보드 배열 확인은 사용자 테스트가 필요하다.
