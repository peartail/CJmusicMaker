# 타임라인 스케일·메트로놈 개발 계획

기준 버전: v0.1031

## 용어

- 시간 눈금자: 전체 트랙이 공유하는 재생 시간을 `분:초`로 보여 주는 윗줄이다.
- 가로 스케일: 같은 화면 너비에 보이는 시간 범위를 바꾸는 확대·축소다. 확대하면 노트 사이 간격이 넓어져 정밀 편집이 쉬워진다.
- 세로 스케일: 트랙 높이를 바꾸는 기능이다. 현재 트랙 경계 드래그로 구현되어 있다.
- 메트로놈: 일정한 박자마다 클릭음을 내어 연주 타이밍을 맞추는 도구다. BPM은 1분 동안의 박자 수다.

## 개발 순서

1. [완료, v0.1030] 루프 영역 아래에 매초 `분:초` 시간 눈금자를 표시한다. 눈금자 클릭·드래그로 Tracktion Transport의 재생 헤드를 이동한다.
2. [완료, v0.1031] `TIME ZOOM`으로 가로 확대·축소하고 `VIEW` 막대로 보이는 시간 구간을 좌우 이동한다. 노트의 실제 Tracktion 시간은 바꾸지 않고 화면의 시간→X 좌표 변환만 조정한다. 노트 본체 드래그로 시간·음높이를 옮기고 오른쪽 손잡이로 길이를 바꾸는 기존 편집도 확대 배율에 맞춰 동작한다.
3. [완료, v0.1031] BPM 설정과 `METRO` ON/OFF를 추가한다. Tracktion Edit의 템포와 Click Track을 직접 사용하므로 클릭음은 PLAY 중 설정한 박자에 맞춰 출력되고, 상태는 프로젝트에 저장된다.

v0.1035에서 확대·이동으로 화면 밖에 놓인 노트, 루프 영역과 재생 헤드를 각 트랙의 타임라인 콘텐츠 경계로 잘라낸다. 음계·악기 라벨 영역은 시간 그래픽과 히트테스트에서 제외한다.

## 단계별 인수 기준

- 시간 눈금은 0초를 `0:00`, 60초를 `1:00`으로 표시한다.
- 가로 확대 후에도 노트와 루프 범위, 재생 헤드가 같은 Tracktion 시간에 정렬된다.
- 메트로놈을 끄면 클릭음이 없고, 켜면 설정한 BPM의 박자에 맞춰 재생 중 출력된다.
