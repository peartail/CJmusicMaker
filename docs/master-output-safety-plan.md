# 마스터 출력 보호 개발 계획

## 문제와 근거

2026-10-18 실제 연주 진단 로그에서 `Generated Keys`의 `post-synth`, `post-track`, `post-master` 피크가 모두 최대 `1.73581445`까지 올라갔다. 디지털 오디오의 일반적인 최대 범위인 `1.0`을 약 74% 초과했으며, 여러 음의 릴리스와 리버브가 겹칠 때 파형이 잘리는 클리핑이 발생할 수 있는 상태였다.

## 목표

- 여러 건반과 트랙이 겹쳐도 Windows 오디오 장치에 `1.0`을 넘는 신호를 보내지 않는다.
- 트랙과 노트의 권위 있는 상태는 기존처럼 Tracktion `Edit`에 둔다.
- 오디오 콜백에서 파일 I/O, 동적 할당, UI 호출, 잠금 및 로그 기록을 하지 않는다.
- 사용자가 출력 상태와 보호 동작 여부를 화면에서 바로 확인할 수 있게 한다.

## 구현 순서

1. Tracktion 마스터 플러그인 목록의 첫 위치에 `MasterSafetyPlugin`을 자동 설치한다.
2. 모든 합산 출력에 `-12 dB` 헤드룸을 적용한다. 최근 측정값 `1.74`는 약 `0.44`까지 내려간다.
3. JUCE 기본 리미터를 `-0.5 dB`, 릴리스 `80 ms`로 적용해 더 큰 합산 피크도 최종 범위 안에 둔다.
4. 리미터 뒤에 기존 `post-master` 진단 탭을 배치해 보호된 파형을 기록한다.
5. 상단에 마스터 출력 미터를 표시하고, 보호 전 입력이 `1.0`을 넘거나 리미터가 동작하면 약 1초간 `PROTECTED`를 표시한다.
6. `--self-test-master-safety`에서 기존 문제값 `1.74`를 입력해 출력이 `1.0` 이하이고 과부하가 감지되는지 검사한다.

## 용어

- **헤드룸(Headroom)**: 여러 소리가 더해질 공간을 미리 남겨두는 여유 음량이다.
- **리미터(Limiter)**: 설정한 최대 음량을 넘는 순간적인 신호를 자동으로 줄이는 장치다.
- **마스터(Master)**: 모든 트랙이 합쳐진 최종 출력 경로다.
- **피크(Peak)**: 아주 짧은 순간을 포함한 파형의 가장 큰 크기다.

## 완료 조건

- 단독 안전성 테스트가 성공한다.
- Debug 빌드가 성공한다.
- 여러 건반을 반복해도 `post-master` 피크가 `1.0`을 넘지 않는다.
- 정상 출력에서는 `SAFE`, 보호가 개입하면 `PROTECTED`가 표시된다.

## 후속 범위

현재 값은 안전한 고정 기본값이다. 실제 믹싱 기능이 확장된 뒤에는 마스터 게인과 리미터 감쇄량 표시를 사용자 조절 항목으로 추가한다. 고정값을 먼저 적용해 불필요한 설정 UI와 프로젝트 호환성 부담을 만들지 않는다.
