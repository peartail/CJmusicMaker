# 신시사이저 기초: 소리가 만들어지는 순서

이 문서는 MusicBitMaker의 생성 악기 프리셋을 사용하면서 필요한 용어를 익히기 위한 입문 자료다. 현재 앱은 외부 녹음 파일 대신 Tracktion Engine의 `FourOsc` 소프트웨어 신시사이저로 음색을 만든다.

## 먼저 전체 흐름 보기

```text
건반 입력(MIDI 노트)
        ↓
오실레이터와 파형: 소리의 원재료 생성
        ↓
엔벌로프: 소리 크기가 시간에 따라 변하는 모양 결정
        ↓
필터: 밝기와 특정 주파수 영역 정리
        ↓
LFO: 음높이·크기·필터 등에 반복 움직임 추가
        ↓
이펙트: 공간감, 반복음, 두께, 거친 질감 추가
        ↓
트랙 믹서: 음량, 좌우 위치, 뮤트, 솔로 조절
```

`MIDI`는 소리 파일이 아니라 “몇 번 음을 언제, 얼마나 세게 눌렀는가”를 기록한 연주 정보다. 같은 MIDI 노트를 다른 신시사이저 프리셋으로 재생하면 연주는 같아도 음색은 달라진다.

## 1. 오실레이터와 파형

### 오실레이터(Oscillator)

오실레이터는 일정한 진동을 만들어 신시사이저 소리의 원재료를 제공하는 발생기다. 실제 피아노의 줄이나 관악기의 공기 기둥에 해당한다고 생각하면 쉽다. 건반의 음이 높아지면 오실레이터의 진동수도 높아진다.

- `주파수(Frequency)`: 1초 동안 진동하는 횟수이며 단위는 Hz다. 주파수가 높을수록 높은 음으로 들린다.
- `피치(Pitch)`: 사람이 인식하는 음의 높이다. 주파수와 밀접하지만 음악적 관점에서 사용하는 말이다.
- `음색(Timbre)`: 같은 음높이와 음량이어도 피아노와 기타를 구분하게 하는 소리의 성격이다.
- `배음(Harmonic)`: 기본 음의 정수배 주파수로 함께 들어 있는 성분이다. 어떤 배음이 얼마나 섞이는지가 음색을 크게 바꾼다.

하나의 프리셋에서 오실레이터를 여러 개 겹칠 수 있다. 두 번째 오실레이터의 옥타브를 올리거나 내리고, 음량을 작게 섞으면 한 음 안에서도 더 풍부한 질감을 얻는다.

### 파형(Waveform)

파형은 진동 한 주기의 모양이다. 모양에 따라 들어 있는 배음이 달라져 소리의 인상이 바뀐다.

| 파형 | 들리는 성격 | 흔한 용도 |
| --- | --- | --- |
| 사인파(Sine) | 가장 순수하고 둥글다. 배음이 거의 없다. | 저음, 부드러운 전자음, 테스트 톤 |
| 삼각파(Triangle) | 사인파보다 조금 밝지만 여전히 부드럽다. | 레트로 게임 저음, 플루트 같은 음색 |
| 사각파(Square) | 비어프처럼 또렷하고 속이 빈 느낌이 난다. | 8비트 리드, 레트로 멜로디 |
| 톱니파(Saw) | 배음이 많아 밝고 거칠며 두껍다. | 패드, 베이스, 강한 리드 |
| 노이즈(Noise) | 일정한 음높이보다 넓은 주파수의 잡음에 가깝다. | 하이햇, 바람, 충격음, 효과음 |

추가로 자주 보는 조절값은 다음과 같다.

- `튜닝(Tune)`: 보통 반음 또는 옥타브 단위로 음높이를 옮긴다. 12반음은 1옥타브다.
- `디튠(Detune)`: 여러 소리의 음높이를 아주 조금 어긋나게 해 더 넓고 두껍게 들리게 한다.
- `펄스 폭(Pulse Width)`: 사각파 계열에서 한 주기 중 높은 부분이 차지하는 비율이다. 값을 바꾸면 같은 사각파라도 얇거나 코맹맹이 같은 다른 음색이 난다.
- `유니슨(Unison)`: 같은 음을 여러 보이스로 동시에 내고 조금씩 디튠하거나 좌우로 벌리는 방식이다.

## 2. 엔벌로프와 ADSR

엔벌로프(Envelope)는 건반을 누르고 뗄 때 소리의 크기나 필터 값이 시간에 따라 어떻게 변할지 정하는 곡선이다. 가장 흔한 형태가 `ADSR`이다.

```text
음량
  ▲             ┌──── Sustain ────┐
  │          /──┘                  │
  │        /                       │＼ Release
  │      / Attack       Decay      │  ＼
  └──────────────────────────────────────▶ 시간
       건반 누름                     건반 뗌
```

- `Attack(어택)`: 건반을 누른 순간부터 최대 크기에 도달할 때까지의 시간이다. 짧으면 즉시 튀어나오고, 길면 천천히 부풀어 오른다.
- `Decay(디케이)`: 최대 크기에서 서스테인 크기까지 내려가는 시간이다.
- `Sustain(서스테인)`: 건반을 계속 누르고 있는 동안 유지되는 크기다. 시간값이 아니라 보통 레벨 값이다.
- `Release(릴리스)`: 건반을 뗀 뒤 완전히 사라질 때까지의 시간이다. 길면 잔향처럼 음이 남는다.

예를 들어 피아노처럼 치는 즉시 소리가 나게 하려면 어택을 짧게 한다. 우주 공간의 패드처럼 서서히 등장하는 소리는 어택과 릴리스를 길게 한다. 필터에도 별도의 ADSR을 적용할 수 있으며, 이때는 음량이 아니라 소리의 밝기가 시간에 따라 변한다.

## 3. 필터

필터(Filter)는 소리의 특정 주파수 영역을 통과시키거나 줄인다. 조명에서 특정 색을 거르는 필터처럼, 이미 만들어진 소리에서 원하는 부분을 남기는 단계다.

- `로우패스(Low-pass)`: 낮은 주파수는 통과시키고 높은 주파수를 줄인다. 컷오프를 내리면 소리가 어둡고 둥글어진다.
- `하이패스(High-pass)`: 높은 주파수는 통과시키고 낮은 주파수를 줄인다. 저음의 울림이나 탁함을 정리할 때 쓴다.
- `밴드패스(Band-pass)`: 중간의 특정 구간만 통과시킨다. 전화기나 라디오 같은 좁은 소리를 만들 수 있다.
- `컷오프(Cutoff)`: 필터가 줄이기 시작하는 기준 주파수다. 신시사이저에서 “밝기”를 가장 직접적으로 바꾸는 값이다.
- `레조넌스(Resonance)`: 컷오프 주변을 강조한다. 적당히 올리면 캐릭터가 생기고, 너무 높이면 날카롭거나 휘파람 같은 소리가 날 수 있다.
- `슬로프(Slope)`: 컷오프 이후를 얼마나 가파르게 줄이는지 나타낸다. 보통 dB/oct 단위로 표기하며 값이 클수록 더 급격히 잘린다.

처음에는 로우패스 필터를 선택하고, 컷오프를 천천히 내렸다 올려 보는 것이 가장 이해하기 쉽다.

## 4. LFO

LFO는 `Low Frequency Oscillator`, 즉 저주파 오실레이터의 약자다. 사람이 음높이로 듣기 어려울 정도로 느리게 반복되는 파형을 만들고, 그 움직임으로 다른 값을 자동 조절한다. 일반 오실레이터가 “소리 자체”를 만든다면 LFO는 “소리를 움직이는 손”에 가깝다.

- `Rate(레이트)`: 움직임이 반복되는 속도다.
- `Depth(뎁스)`: 움직이는 폭이다. 너무 크면 효과가 과장된다.
- LFO → 피치: 음높이가 주기적으로 흔들리는 `비브라토(Vibrato)`가 된다.
- LFO → 음량: 음량이 주기적으로 흔들리는 `트레몰로(Tremolo)`가 된다.
- LFO → 필터 컷오프: 밝기가 반복해서 열리고 닫히는 움직임이 된다.
- LFO → 팬: 소리가 좌우로 움직인다.

처음에는 속도를 느리게, 깊이를 작게 놓는 것이 좋다. LFO가 효과를 낼 대상과 연결되지 않았다면 Rate와 Depth를 바꿔도 소리가 달라지지 않는다. 이 연결 관계를 `모듈레이션 라우팅(Modulation Routing)`이라고 한다.

## 5. 이펙트

이펙트(Effect)는 기본 음색 뒤에 적용해 공간, 반복, 두께, 질감을 더하는 처리다.

### 딜레이(Delay)

원래 소리를 조금 늦춰 반복한다. 메아리처럼 들리며 공간감과 리듬감을 만든다.

- `Time`: 반복되기까지의 시간
- `Feedback`: 반복된 소리가 다시 입력으로 돌아가는 양. 높을수록 반복 횟수가 늘어난다.
- `Mix` 또는 `Dry/Wet`: 원음(Dry)과 처리된 소리(Wet)의 비율

### 리버브(Reverb)

방, 홀, 우주선 내부처럼 어떤 공간에서 소리가 여러 표면에 반사되는 느낌을 흉내 낸다.

- `Size`: 공간의 크기
- `Damping`: 고음이 얼마나 빨리 흡수되는지
- `Width`: 스테레오로 퍼지는 폭
- `Mix`: 원음과 잔향의 비율

### 코러스(Chorus)

원음을 아주 짧게 지연하고 음높이를 미세하게 흔든 복사본과 섞는다. 여러 명이 함께 연주하는 것처럼 두껍고 넓어진다. 패드나 깨끗한 기타 계열 음색에 자주 사용한다.

### 디스토션(Distortion)

파형을 강하게 눌러 새로운 배음을 만들고 거칠게 한다. 약하게 쓰면 존재감이 생기고, 강하게 쓰면 찢어지는 소리가 난다. 출력 레벨도 함께 커질 수 있으므로 트랙 음량을 확인한다.

### 비트크러셔(Bitcrusher)

디지털 음질의 해상도나 샘플링 속도를 의도적으로 낮춰 오래된 게임기 같은 거친 계단형 질감을 만든다. 현재 기본 프리셋은 사각파와 짧은 엔벌로프로 8비트 인상을 내며, 전용 비트크러셔는 후속 이펙트 단계에서 추가할 수 있다.

## MusicBitMaker의 현재 프리셋

이 프리셋들은 제3자 녹음이나 특정 게임의 음원을 복제하지 않고 신시사이저 파라미터만으로 만든 원본 설정이다.

| 프리셋 | 핵심 설정 | 들어볼 점 |
| --- | --- | --- |
| Generated Keys | 사인파 + 작은 삼각파, 짧은 어택, 약한 리버브 | 부드러운 기본 건반 |
| Retro Pulse | 펄스 폭을 줄인 사각파 + 낮은 삼각파 | 짧고 또렷한 레트로 느낌 |
| 8-Bit Lead | 두 사각파를 한 옥타브 간격으로 겹침, 매우 짧은 어택 | 멜로디가 앞으로 튀어나오는 느낌 |
| Space Beep | 사인파 + 높은 삼각파, 딜레이와 리버브 | 삑 소리가 반복되며 공간으로 퍼지는 느낌 |
| Cosmic Pad | 톱니파 유니슨 + 삼각파, 긴 어택과 릴리스, 코러스·리버브 | 천천히 넓어지는 배경 레이어 |

`Space Beep`은 특정 게임의 음원을 사용하거나 그대로 복제한 것이 아니다. 우주 SF 장르에서 흔히 느껴지는 짧은 전자음과 공간계를 독자적인 파라미터 조합으로 만든 것이다.

## Track Settings에 넣을 수 있는 항목

v0.1022부터 트랙 우클릭의 `Settings` 아래에서 `Change Instrument...`를 연다. v0.1023에서는 같은 메뉴의 `Sound Controls...`에서 Oscillator 1 파형, Attack/Release, Filter Cutoff/Resonance, Reverb Mix를 직접 입력하고 적용할 수 있다.

| 설정 묶음 | 대표 조절값 | 귀로 느껴지는 변화 |
| --- | --- | --- |
| Instrument | 프리셋 선택 | 여러 값을 한꺼번에 바꿔 기본 음색을 선택한다. |
| Oscillator | 파형, Level, Tune, Detune, Pulse Width | 소리의 기본 재료, 두께와 음높이를 바꾼다. |
| Amp Envelope | Attack, Decay, Sustain, Release | 건반을 누르고 뗄 때 음량이 변하는 시간을 바꾼다. |
| Filter | Type, Cutoff, Resonance | 소리의 밝기와 특정 주파수의 강조를 바꾼다. |
| LFO | Target, Rate, Depth | 피치·음량·필터가 반복해서 흔들리는 방식을 정한다. |
| Effects | Distortion, Chorus, Delay, Reverb와 Mix | 거친 질감, 두께, 반복음, 공간감을 더한다. |

첫 편집 화면은 모든 값을 한꺼번에 노출하기보다 `Oscillator 1 파형`, `Attack/Release`, `Filter Cutoff/Resonance`, `Reverb Mix`로 구성했다. `Oscillator 2`, 세부 튜닝, LFO 연결표는 기본 조절이 안정된 뒤 추가할 수 있다. 각 값은 Tracktion `Edit`의 FourOsc 플러그인 상태에 저장되어 프로젝트 저장·불러오기와 실제 재생이 같은 데이터를 사용한다.

## 앱에서 연습하는 순서

1. 트랙 하나를 선택하고 `Generated Keys`로 같은 멜로디를 녹음한다.
2. 프리셋만 `Retro Pulse`, `8-Bit Lead`, `Space Beep`으로 바꾸며 음색 차이를 듣는다.
3. 새 트랙을 추가하고 `Cosmic Pad`를 선택한 뒤 긴 음을 낮은 음량으로 겹친다.
4. 각 트랙의 Volume을 조절해 주선율과 배경의 크기를 나눈다.
5. Pan으로 두 트랙을 좌우에 조금씩 배치한다.
6. Mute로 한 트랙을 끄고, Solo로 한 트랙만 들으며 각각의 역할을 확인한다.

처음부터 모든 값을 동시에 바꾸지 말고 한 번에 하나만 바꾸는 것이 좋다. 특히 리버브·딜레이·디스토션은 작은 값부터 올리고, 갑자기 큰 소리가 날 수 있으므로 헤드폰과 스피커의 물리 음량을 낮게 시작한다.

## 짧은 용어 사전

| 용어 | 뜻 |
| --- | --- |
| 소프트웨어 신시사이저 | 컴퓨터 계산으로 소리를 생성하는 가상 악기 |
| 보이스(Voice) | 동시에 울릴 수 있는 독립적인 한 음 또는 발음 단위 |
| 폴리포니(Polyphony) | 동시에 여러 음을 내는 기능 또는 가능한 최대 음 수 |
| 모노포닉(Monophonic) | 한 번에 한 음만 내는 방식 |
| 파라미터(Parameter) | 사용자가 바꿀 수 있는 음색 설정값 |
| 프리셋(Preset) | 여러 파라미터를 미리 조합해 저장한 음색 |
| 레이어(Layer) | 여러 트랙이나 음색을 겹쳐 하나의 음악으로 만드는 것 |
| 믹싱(Mixing) | 트랙별 음량·위치·톤·효과를 조절해 전체 균형을 잡는 과정 |
| 마스터링(Mastering) | 완성된 믹스를 최종 배포 음량과 포맷에 맞게 다듬는 과정 |
